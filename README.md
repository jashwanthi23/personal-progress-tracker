# Personal Progress Tracker

A full-stack cross-platform mobile application built to demonstrate modern mobile and backend development skills.

The application allows users to manage personal goals and tasks, track progress, and view their overall progress through a dashboard.

## Tech Stack

### Mobile Application
- React Native
- Expo
- TypeScript

### Backend
- Node.js
- Express
- TypeScript
- REST API

### Database
- PostgreSQL
- Prisma ORM

### Authentication
- Firebase Authentication

### Development & Deployment
- Git
- GitHub
- ESLint
- Prettier

## Supported Platforms

- Android
- iOS
- Web

## Planned Features

- User registration
- User login and logout
- Password reset
- Create tasks
- Edit tasks
- Delete tasks
- Track task progress
- Task status management
- Dashboard
- Personal profile
- REST API integration
- Firebase authentication
- PostgreSQL database integration
